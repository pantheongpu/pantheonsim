# Two external test suites run on the simulator, one line a program and profile: what each printed. Unlicensed or GPL code is not in
# this repository: tools/tcpapers/ has our own programs. Provenance: run 2026-11-16 on server3, SASS engine (PTX engine printed the same
# on every line unless a ' | PTX:' tail says otherwise); cubin built for the profile's own architecture, CUDA 13.0.
#   f_*  = Fasi, Higham, Mikaitis, Pranesh (PeerJ CS 7:e330, 2021) github.com/north-numerical-computing/tensor-cores-numerical-behavior (GPL-2.0):
#          one letter a check in the program's order, P = PASS, F = FAIL. f_binary16 has 17 checks, f_bf16 and f_tf32 13, f_binary64 11.
#          The checks encode the Volta / Turing / Ampere findings; F on a Hopper rule or a sequential sum means the feature differs.
#   h_*  = Khattak and Mikaitis feature tests for HPEC 2025 (github.com/faiziktk/IEEE_HPEC2025_block_FMA_tests, no licence stated): the program's own
#          values: 1bit/2bit = one / two extra alignment bits detected, carry = extra carry bits, fma = FMA size, round = final rounding of the
#          f32 result, f16 result, then alignment roundings (RZ truncation, RNE nearest even).
#   Fasi's A100-bf16 and A100-tf32 write h_b[-1] when j is 0 (a missing brace; an out-of-bounds heap write that corrupts the heap and aborts
#   at exit under the simulator's allocator, found with AddressSanitizer). The runs below are of copies with the braces added; on the
#   RTX 3060 the original and the copy print the same.
